# 标注交互修复 · 2026-10-31

## 1. 连续填写、一次确认

批量模式改为整组草稿。阶段选中值立即进入下拉框，后台自动重算这组草稿的门控，左右臂对应的必填项随之更新。填写其他字段不会逐项弹出覆盖确认，最后点击一次“确认保存全部 N 项”。

预览使用 SQLite 保存点计算真实区间的影响、跳过、适用未知和逐帧覆盖例外，随后全部回滚，不写入正式标注或修订历史。提交按依赖顺序在一个事务内写入；任何字段失败则整组回滚，一次撤销/重做处理整组。逐帧覆盖仍优先于区间，例外数量会明确显示。下拉框展示的是本组赋值目标，提交按各帧的实际适用性生效。

未确认的整组草稿保存在浏览器和 SQLite 偏好中，刷新后可恢复。可以移除单项、取消整组；旧 schema 草稿不能误提交到新版本。单帧模式仍保持自动保存。

## 2. 决策帧固定的未来画面

行为复核新增未来参考面板，默认显示 t+0.1、t+0.2、t+0.25 秒的三路相机，标明真实源帧和时刻，可点击放大。参考跨度可选0.25/0.5/1/2/5秒，不移动当前决策帧或标注目标。

30 FPS下，t+0.25秒使用不晚于目标的真实帧，例如决策帧150（5秒）对应153 / 156 / 157帧（5.1 / 5.2 / 5.233333秒）。请求超过episode可用未来时显示缺失卡，不补造最后一帧。更长参考仅供行为复核，自动 adviser 计算仍限制在最多0.25秒连续approved窗口。

切回状态标注时立即移除未来面板，服务端也返回空future列表；不会把未来图像加入DSE输入。未来请求和历史请求共用游标版本，过期响应不能覆盖新帧。行为审核按钮也只审核该模式下的字段，不会尝试用行为模式发布状态标签。

## 3. 带依赖检查的删除

字段和类别增加删除入口，删除前列出阻止项及历史标注使用量。检查覆盖 all/any/not 内的 eq/ne/in 引用、指定左右臂/全局引用、独立审核关联、unknown_id 和内置语义一致性依赖。phase是基础字段，不可直接移除；被依赖项需先解除引用。

无依赖项目可以先从配置草稿删除，发布后从活动表单、导出schema和head_spec移出。旧schema及原始标注记录保留，删除身份进入retired_fields / retired_classes登记，后续版本不能复用已删除key/ID；自动新增类别也避开这些ID。

已删除类别的旧标注在当前版本显示missing/needs_review、mask=0，并显示原类别ID；原值仍在修订/区间中，导出后重开也能追溯。未发布的删除可撤销，其他后续编辑不会被撤销删除覆盖。发布schema后同时刷新episode审核进度。
